# MEAT EXPRESS — Premium Selection for Shabu & Buffet

แคตตาล็อกสินค้าวัตถุดิบนำเข้าพรีเมียม สำหรับร้านชาบูและบุฟเฟ่ต์

หน้าเว็บเดียว static ไม่มี build step ไม่มี dependency — เปิด `index.html` ได้ตรงๆ

ปิดท้ายด้วยแถบแดงเต็มความกว้างที่มีโลโก้ขาว — แดงจึงปรากฏหนักแน่นแค่หัวและท้าย

โลโก้ทั้งสองไฟล์สร้างจากต้นฉบับพื้นแดงไฟล์เดียว โดยแยก alpha ตามความสว่าง
แล้วเติมสีขาว/แดง — ได้มาร์กพื้นโปร่งที่วางได้ทั้งบนขาวและบนแดง

## บนมือถือ

- มี **แถบติดต่อลอยล่างจอ** (`.dock`) แสดงเฉพาะจอกว้าง ≤ 800px
  ปุ่มซ้าย *โทรเลย* → `tel:` · ปุ่มขวา *แชท LINE* → เปิดแอป LINE
- ปุ่มสูง 54px เผื่อพื้นที่นิ้ว และเผื่อ `env(safe-area-inset-bottom)` ให้ iPhone รุ่นมีขอบล่าง
- รูปสินค้าเปลี่ยนสัดส่วนเป็น 4:3 และเรียงเป็นคอลัมน์เดียวอัตโนมัติ

## แก้ข้อความ / เพิ่มสินค้า

สินค้าแต่ละตัวคือ block `<article class="item">` ใน `index.html` ประกอบด้วย

| ส่วน | class | หมายเหตุ |
|---|---|---|
| ชื่ออังกฤษ | `.name-en` | เป็นลิงก์ anchor ของตัวเอง |
| ชื่อไทย | `.name-th` | สีทอง |
| คำโปรย | `.desc` | หนึ่งบรรทัด |
| จุดขาย | `.chips .benefit` | พื้นทอง |
| สเปก/ข้อเท็จจริง | `.chips .spec` | เส้นขอบ เช่น ความหนา, แหล่งนำเข้า |

สลับรูปซ้าย-ขวาด้วยการใส่/เอา class `flip` ที่ `<article>`

เพิ่มสินค้าตัวใหม่ = ก๊อป block `<article>` ทั้งอัน เปลี่ยน `id`, ข้อความ, และ path รูป
แล้วอย่าลืมสลับ `flip` ให้ลายสลับซ้ายขวาต่อเนื่อง
